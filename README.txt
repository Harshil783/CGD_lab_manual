CGD PRACTICALS WEBSITE
======================

OPEN LOCALLY
1. Extract this ZIP file.
2. Open index.html in a modern web browser.
3. Select any practical card to open its page.

HOST ONLINE
Upload the contents of this folder to any static web host (for example, GitHub Pages or Netlify).
No server, database, build step, or package installation is required.

CONTENTS
- index.html: landing page with links to all 13 practical pages
- practicals/: one HTML page per practical
- assets/: shared dark theme stylesheet and copy-code interaction

The website contains the practical sections only. The PDF cover and index pages are not included.
