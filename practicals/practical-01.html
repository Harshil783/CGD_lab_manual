Basic Graphics Functions

Aim

To study and use the basic graphics functions (line, rectangle, circle, ellipse, arc, bar, polygon, pieslice, outtextxy) of the C/C++ graphics library.

Input

No user input is required. All values are defined inside the program.

Program / Code

#include <graphics.h>
#include <conio.h>

int main() {
  int gd = DETECT, gm;
  int poly[] = {380, 240, 440, 320, 320, 320, 380, 240};

  initgraph(&gd, &gm, "C:\\TURBOC3\\BGI");

  // Line
  setcolor(WHITE);
  line(50, 60, 200, 60);
  outtextxy(50, 40, "line");

  // Rectangle
  setcolor(YELLOW);
  rectangle(50, 100, 200, 180);
  outtextxy(50, 85, "rectangle");

  // Circle
  setcolor(GREEN);
  circle(300, 140, 40);
  outtextxy(280, 85, "circle");

  // Ellipse
  setcolor(CYAN);
  ellipse(450, 140, 0, 360, 70, 35);
  outtextxy(430, 85, "ellipse");

  // Arc
  setcolor(MAGENTA);
  arc(100, 280, 0, 180, 50);
  outtextxy(80, 295, "arc");

  // Bar
  setcolor(RED);
  setfillstyle(SOLID_FILL, RED);
  bar(200, 240, 280, 320);
  outtextxy(215, 330, "bar");




    // Polygon
    setcolor(LIGHTBLUE);
    drawpoly(4, poly);
    outtextxy(350, 330, "drawpoly");

    // Pie slice
    setcolor(WHITE);
    setfillstyle(HATCH_FILL, LIGHTGREEN);
    pieslice(550, 290, 0, 120, 50);
    outtextxy(520, 330, "pieslice");

    outtextxy(200, 400, "Basic Graphics Functions");

    getch();
    closegraph();
    return 0;
}

Output

The graphics window displays a line, rectangle, circle, ellipse, arc, bar, polygon and pie slice, each with its label.
